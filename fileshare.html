FileShare.

Over two weeks, my classmates and I built an end-to-end encrypted file-sharing system for the web and desktop.

Explore FileShare on GitHub ↗

Inside the web client

What I designed

My focus was the path a file takes from sender to recipient. I led the design of the cryptographic sharing flow and the OTP flow, and built most of the React client. Our team also built a native Qt client in C++ and a Python server.

We used Argon2id for password-based key derivation and envelope encryption to protect keys. For sharing, we combined trust on first use with X3DH key agreement. The goal was to let the server coordinate delivery while the clients retained control of the file contents.
